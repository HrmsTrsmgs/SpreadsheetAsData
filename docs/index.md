# SpreadsheetAsData Documentation

SpreadsheetAsDataは、Excelをインストールしていない環境でも `.xlsx` ファイルを扱うためのライブラリです。

C#版のAPIリファレンスは、ライブラリ本体のXMLドキュメントコメントから生成します。
Ruby版のAPIリファレンスは、Ruby版の再整備後に追加する予定です。
