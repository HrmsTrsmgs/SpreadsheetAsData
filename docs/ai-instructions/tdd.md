# TDD工程別コンテキスト

TDDの入口はリポジトリ内の `.agents/skills/spreadsheet-tdd/SKILL.md` とする。
このファイルは旧指示からの参照先として残す索引であり、全工程の指示を常時読み込ませるものではない。

進行役は `tdd/run.md`、各担当は `tdd/common.md` と自分の工程の文書だけを読む。
モデル選択は進行役だけが必要時に `tdd/models.md` を参照する。

* Red: `tdd/red.md`
* Green: `tdd/green.md`
* Refactor: `tdd/refactor.md`
* 新しい主チャットからの開始文: `tdd/start.md`

既存の安全・Git・レビュー規則は `AGENTS.md` と `common.md` に従う。
