# 新しい主チャットからの開始文

この文書を参照して、新しいローカルの主チャットで次のように依頼する。要求欄は今回の具体的な要求へ置き換える。この導入作業中には実行しない。

```text
$spreadsheet-tdd このプロジェクトで次の要求を実装してください。

要求: ＜今回の要求＞

Red、Green、必要ならRefactorを、親の会話履歴を継承しない担当コンテキストで順番に進めてください。この要求の範囲で工程担当の起動と成果物の受け渡しを許可します。担当同士の相談、工程間のAI意味レビュー、追加承認は不要です。worktreeはコンテキスト分割のために作り直さないでください。

Green後は未コミット差分を私がIDEで確認します。了承後にGコミットを作成してください。Refactorに実変更がある場合も、未コミット差分の確認後にFコミットを作成してください。変更がなければ空コミットは作らないでください。

工程を越える未決定の外部契約が不可欠な場合だけ、そこで止めて判断事項を示してください。
```
