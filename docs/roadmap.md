# SpreadsheetAsData 作業ロードマップ

この文書は、今後の調査、整備、公開準備の観点を記録する。
作業の進行に合わせて更新してよい。

## 作業開始時の調査

未把握の領域を変更する前に、次を確認して必要に応じて報告する。

* Gitリポジトリの状態
* ソリューションとプロジェクトの構成
* 各プロジェクトの役割
* 対象.NETバージョン
* 現在のExcel操作方式
* 既存の公開API
* 既存の利用コード
* テストプロジェクトと既存テスト
* 参照している依存パッケージ
* 現在のビルド状態
* 現在のテスト結果
* Open XML SDKへ置き換える候補箇所
* 公開時に除外すべき情報

確認できた事実、推測、提案を区別する。
大きな実装変更を始める前には、明示的な許可を得る。

## READMEに記載する内容

READMEには少なくとも次を記載する。

* 解決する問題
* 想定利用者
* Open XML SDKを直接使う場合の問題
* このライブラリを使う利点
* ビルド方法
* テスト方法
* 最小使用例
* 主要機能
* 設計方針
* 制約
* 未対応機能
* 今後の拡張余地

## 公開時の注意

* 実在顧客のデータ、企業秘密、個人情報を含めない。
* APIキー、秘密鍵、アクセストークン、接続文字列を含めない。
* ユーザー名やローカル固有の絶対パスをコード、ログ、READMEへ残さない。
* 公開前にGitの追跡対象ファイルと履歴を確認する。
* サンプルやテストデータを追加する前に、公開可能な内容か確認する。
